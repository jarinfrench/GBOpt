# Superseded Documentation

Files in this directory are retained for historical reasoning only. They are not implementation instructions and do not override active documents.

Each superseded document should include a notice near the top stating:

- that it is superseded;
- which active document replaced it;
- why it was retained;
- that it must not be used for branch creation, PR sequencing, or current API decisions.

Current authority begins with `../MASTER_PLAN.md` and follows the precedence described in `../README.md`.
